# jekyllnhyde.com

Site vitrine statique de Jekyll N' Hyde (HTML/CSS/JS pur, sans WordPress ni dépendance).

- Pages : `index.html`, `showreel/`, `pictures/`, `videos/`, `contact/`, `404.html`
- Styles : `assets/css/site.css` — Scripts : `assets/js/site.js`
- Images : `assets/img/` (portfolio dans `assets/img/work/`)
- Polices auto-hébergées (aucun appel à Google Fonts)
- Hébergement : statichost.eu (`statichost.yml`), publication automatique à chaque modification de la branche principale

Les URL sont identiques à celles de l'ancien site WordPress, pour conserver le référencement.
